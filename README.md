# Astro Idle (working title)

An idle / incremental shooter for Android, built in **Unity 6 (6000.4.6f1)**.

A small triangular ship (a nod to *Asteroids*) flies itself around a play field, auto-firing every weapon it owns
at waves of asteroids, drones and gunships. Kills earn **credits**. Credits buy **upgrades** (ship and per-weapon).
Reaching **milestones** unlocks new weapons to buy. The loop is modeled on idle games like *Idle Drill*: watch numbers
go up, spend, push further, hit a wall, upgrade, push again. Progress continues (at reduced efficiency) while the app
is closed.

> **Status:** first playable pass, about 5 minutes of content (10 waves, 1 boss, 3 weapons, 5 enemy types).
> All balance numbers are a **baseline to iterate on**. See [docs/GAME_DESIGN.md](docs/GAME_DESIGN.md).

---

## Quick start

1. Install the **Android Build Support** module for Unity 6000.4.6f1 in Unity Hub (needed for phone builds only).
2. In Unity Hub: **Add → Add project from disk** and select this folder.
3. Open the project. When Unity asks to enable the new Input System backends, click **Yes** (the editor restarts).
4. The editor auto-creates `Assets/_Project/Scenes/Main.unity`. Open it, set the Game view to a portrait phone
   resolution (e.g. 1080x2400) and press **Play**.

Full step-by-step instructions, including building to a phone, are in **[docs/BUILD_AND_RUN.md](docs/BUILD_AND_RUN.md)**.
